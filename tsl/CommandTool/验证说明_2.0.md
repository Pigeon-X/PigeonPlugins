# CommandTool 2.5.0 验证说明

## 结论与范围

本次只构建 UTSL 原生 CommandTool。基线为官方 UnifierTSL 0.3.1 / TShock 6.1 / Terraria 1.4.5.8；目标 .NET 9，构建 SDK 为 10.0.401。不构建普通 TShock 版，不改 BoundaryTransfer，不改实服插件、配置或世界。

**CommandTool 只执行指令**：开关、压力板、拉杆、标牌、区域的触发都只运行指令；不包含传送、跨世界、落点或边界判定代码。旧 2.0.x 配置里的 `"传送"` 段会忽略，旧传送动作会移除并记录。

发布源码仅采用 `native/*.cs`。旧兼容壳与嵌套源码副本没有参与编译。安装包仅包含本插件，不重新分发或替换服务器核心依赖。

证据随源码包附带，包括完整构建、回归与加载日志；安装包提供本说明和空绑定模板。

### 指令静默

- 真实 TSPlayer 的成功、错误消息，以及 ChatHelper 的单发、作者单发、广播、作者广播四个出口：在自动动作范围内均无聊天输出。
- 范围之外与独立并发上下文的正常聊天可继续显示；没有全服关键字过滤或给玩家设置持久禁言状态。
- 真实 Legacy Command.Run 执行一次，指令内部成功/错误/广播静默；故意抛错不进入另一条分发路径重放。
- 同名 Legacy 注册只进入首个有权限的处理器，避免一个动作调用多个同名插件。
- 使用官方注册流程实际安装 TShock V2 指令后，验证 `home`、`warp` 成功结果、`warp` 不存在及 `home` 死亡错误均不发给玩家。
- 上述 V2 测试保留真实指令解析、权限检查与返回结果，但测试末端的 Spawn/Teleport 使用显式桩，不发生真实客户端传送，不冒充联网成功。
- 继承 ExecutionContext 的迟发广播继续静默；同连接迟发普通逻辑可用但额外权限已撤回；槽位换人后的动态 getter 访问被拒绝。
- 执行前后真实 Group 引用、tempGroup 和常规权限不被本工具提权逻辑修改。

### 配置与迁移

- 中英文旧区域、开关、标牌，旧区域总开关和开关独立启用语义。
- 标牌可空管理员身份继承、旧自定义编辑/绑定权限，以及旧标牌总停用不能被合并后重新激活。
- 缺世界禁用、旧空占位跳过、临时权限和父组筛选字段保留、深拷贝、幂等和冲突拒绝。
- 重复 JSON 属性、过深或过大的数据、危险管理自绑定、超多动作、非法数值拒绝。
- **旧传送动作被移除并写入迁移记录**；新配置不再生成传送段。
- 保存后严格读回、原子替换保留上版备份、坏配置不覆盖有效文件。
- 真实文件监视器在合法、非法、误放旧模式、再恢复合法配置四种情况下工作；非法内容保留上次有效运行配置。

### 实体、区域与保护

- 真实 136 小开关、135 压力板、2×2 拉杆锚点归一化；虚化拉杆不可执行但仍能被保护。
- 指令开关拆改拒绝并同步原图格；普通未绑定开关/压力板放行；倒重力不绕过；明确编辑权限放行。
- 真实标牌点击、旧空文字快照兼容、点击后确认防重、伪造 SignSlot/坐标拒绝、原实体同步；普通标牌放行。
- 区域进入停留、离开取消、零停留、执行后锁存、个人冷却、重叠最高优先级和同优先级稳定 ID、到达抑制、死亡/重载重置。
- 区域本身及向外 5 格：边界格不可破坏、第 6 格不保护、管理员可编辑；批量图格与底层销毁同样受保护。
- 选区期间该玩家的图格修改被取消并回发；`建立`/`取消` 后恢复。点1/点2为单格，占位1/占位2为玩家占用框，两种模式不会混用。
- 区域只接受指令动作；没有目标坐标或落点字段。

## 尚需真实客户端验收

本次没有真实多人客户端或长时间压力测试。正式上线前应在同版本测试服完成：

1. 先停用旧 SignCommand 和重复 CommandTool，确认单一新版插件加载。
2. 迁移预览并核对每个来源世界；未指定世界的项目保持禁用。
3. 分别实测开关、压力板、拉杆四格、标牌点击/确认，绑定 `warp`、`home` 及第三方命令，观察触发者、旁观者、拥有日志权限的管理员均无自动聊天提示。
4. 同时让另一名玩家正常聊天、手动用指令，确认没有被静默范围误吞。
5. 测试普通实体与绑定实体拆改、虚化、爆炸和支撑连锁，以及管理员拆除后重建不继承旧绑定。
6. 测试区域计时离开取消、死亡取消、重叠优先级、独立多人冷却，以及区域指令执行。
7. 切图、热重载、插件卸载与同槽位重连，确认只处理原连接。
8. 核对第三方命令是否绕开标准消息出口或切断 ExecutionContext。

## 已知兼容边界

- 自动静默覆盖 TShock 标准结果与 TSPlayer/ChatHelper 消息；故意切断执行上下文的第三方定时器、直接原始网络包，以及绕开标准 API 的外部槽位操作，不承诺统一归属或拦截。
- 第三方指令若直接 `Group.HasPermission` 而非 TSPlayer/CommandExecutor 检查权限，不承诺本次临时授权；不会为兼容它而修改真实组。
- 隐藏目录不阻止任意第三方抓包/原始消息审计；服务器诊断日志不删。
- 旧提示文字保留供迁移对照，按当前要求不自动显示；旧提示颜色不恢复，迁移记录说明。
- CommandTool 不处理传送/落点；边界传送、跨世界和落点安全判定属于 BoundaryTransfer。
