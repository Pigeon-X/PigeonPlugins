# CommandTool 2.5.1 · 仅 UTSL 原生指令版

适配基线：UnifierTSL 0.3.1 / TShock 6.1 / Terraria 1.4.5.8，目标 .NET 9。不是普通 TShock 插件，不加载旧兼容壳。

**职责边界：CommandTool 只负责开关、标牌、区域的指令执行。传送、跨世界、落点和边界判定全部由 BoundaryTransfer 负责，本插件不包含任何传送代码或配置。**

## 功能

- 标牌、指令开关、矩形区域放入一个版本化配置；绑定明确限定世界。
- 自动触发的指令统一无聊天提示：不输出成功/错误结果，不广播“某玩家执行了指令”，并按本次执行上下文拦截指令内部发送的聊天与广播。`warp`、`home` 无需另加静默前缀；服务器诊断日志保留。
- 仅保护**启用且有动作的绑定实体**。普通开关、普通标牌不受保护。支持 **136 小开关**、**135 压力板**、**132 2×2 拉杆**的任意格归一化。保护包括直接拆改、覆盖其位置的批量图格更新、爆炸/支撑连锁的底层销毁。
- **区域保护**：已配置区域本身及向外 **5 格**默认不可破坏，普通玩家不能挖/改，也拦截批量图格与爆炸/支撑连锁销毁；管理员需要 `commandtool.edit` 才能编辑。外扩格数可在配置中调整（0～20）。
- 区域用世界更新状态机：进入后计时，离开、死亡、断线、换图、配置重载均取消等待。同一区域执行后必须离开再进入；重叠区按优先级、ID 稳定选一个。
- 自动指令使用真实玩家，不更换 `TShock.Players`、不临时写真实用户组或 `tempGroup`；绑定中的提权和临时权限只在当次调用的权限检查中有效，结束后撤销。
- 选中实体后的新增/删除动作、冷却和身份修改先存草稿；“取消”不会改运行配置，“完成”才验证并保存。
- **不提供传送动作**。旧 2.0.x 配置里的 `"传送"` 段会被忽略；旧动作中的 `"类型":"传送"` 会被移除，并写入迁移记录。请改用 BoundaryTransfer 处理边界传送。

## 安装与互斥

1. 先停止测试服并备份原来的插件和配置。
2. **停用并移走旧 SignCommand 插件及重复的旧 CommandTool**。本版已含标牌指令；若原生初始化序列发现 SignCommand，会拒绝初始化以防一按执行两次。
3. 安装包的 `plugins/CommandTool.dll` 放入 UTSL 的对应插件目录。不要复制参考发行版的核心依赖覆盖服务器。
4. 新配置自动注册于 `config/CommandTool/CommandTool.v2.json`。初始为空，不自动导入旧文件、不保护普通实体。
5. 新版必须显式包含 `"配置版本": 2`。坏 JSON、重复属性、旧模式误放新路径或不合法数值，不会自动覆盖原文件；有效运行配置保留。
6. 外部修改 `CommandTool.v2.json` 不会自动生效；执行 `/工具 重载` 或 TShock `/reload` 才重新读取。

管理保存用同目录临时文件写入并刷新后原子替换；每次替换保存一个时间戳 `.bak`。失败时不先截断有效文件，残留 `.tmp` 可供人工恢复。备份不自动删除。

## 隐藏管理入口

拥有 `commandtool.admin` 可用 `/工具`、`/commandtool`。**不使用 `/ct`**，避免与 custom 等插件冲突。开关兼容别名 `/开关`、`/kg`、`/switch`；标牌兼容别名 `/标牌`、`/sign`、`/signcommand`、`/sc`。

这些入口不注册进公共指令目录，不出现在 `/help` 和基于该目录的列表中；消息在 TShock 常规审核广播前消费，只向操作人回复。

原有 `signcommand.bind` 或迁移的自定义标牌绑定权限只管理标牌草稿；旧 `开关` 权限只管理开关草稿，不自动取得区域、迁移、世界或按 ID 管理权限。保护编辑使用 `commandtool.edit`，标牌另外兼容迁移的旧编辑权限。

### 标牌 / 开关

```text
/工具 标牌 选择
# 点击目标标牌
/工具 添加 "warp 大厅"
/工具 冷却 3
/工具 完成

/工具 开关 选择
# 点击小开关、压力板或拉杆任意格
/工具 添加 "home"
/工具 完成
```

其他草稿操作：

```text
/工具 提权 true
/工具 提权 false
/工具 删除 1
/工具 取消
/工具 删除
```

`删除 1` 从草稿中移除第一个动作，须“完成”才保存；不带参数的“删除”解除所选实体绑定。只允许信任的管理员绑定提权指令。管理入口禁止绑定到自身，避免递归与权限委托失控。

**压力板和其他开关一样只执行指令；本插件没有任何传送动作可绑定。**

### 区域

只有两种选择模式，避免混用：

**单格点模式**：`点1`、`点2` 各记录脚下**单格**，用作矩形对角。

```text
/工具 区域 点1
/工具 区域 点2
/工具 区域 建立 门口 3
```

**玩家占位模式**：`占位1`、`占位2` 记录玩家实际占用的图格框，常见 2×3，不用够到右下角。

```text
/工具 区域 占位1
/工具 区域 占位2
/工具 区域 建立 门口 3
```

占位框可指定尺寸：

```text
/工具 区域 占位1 3x3
/工具 区域 占位2 3x3
/工具 区域 建立 门口 3
```

- `点1`/`点2` 别名 `set1`/`set2`；`占位1`/`占位2` 别名 `area1`/`area2`。
- 设置点1或占位1会切换当前模式并清空第二个选择，不会把两种模式混在一起。
- **选区期间该玩家的图格修改会被取消并回发**，防止用镐子/物品敲掉方块；`建立`或`取消`后恢复。
- `建立 <ID> [停留秒]` 使用当前模式的两个选择；只设了第一个时，第二个取当前脚下同类型位置。
- `指令 <ID> <指令>`：给区域添加指令动作，最多 32 条。
- `删除动作 <ID> <序号>`：删除区域内的一条指令。
- 矩形边界含端点，检测玩家中心 X 与脚底 Y。倒计时仅内部状态，不向聊天发送提示。
- **建立后的区域本身及向外 5 格默认不可破坏**；普通玩家挖/改会被拒绝并回发原图格，批量图格和爆炸/支撑连锁也会被拦截。管理员用 `commandtool.edit` 仍可编辑。
- 区域只执行指令；不做传送、不读取目标坐标、不搜索落点。

### 查询与管理

```text
/工具 列表 1
/工具 启用 <ID> [归属世界]
/工具 禁用 <ID>
/工具 删除 <ID>
/工具 重载
```

绑定自身带冷却。自动动作最小有效间隔 250ms；不同玩家、不同绑定互不使用全局冷却。

## 配置

```json
{
  "配置版本": 2,
  "启用": true,
  "区域检测间隔_毫秒": 100,
  "管理权限": "commandtool.admin",
  "编辑保护实体权限": "commandtool.edit",
  "旧标牌编辑兼容权限": "signcommand.edit",
  "旧标牌绑定兼容权限": "signcommand.bind",
  "保护指令标牌": true,
  "保护指令开关": true,
  "保护区域": true,
  "区域保护外扩_格": 5,
  "点击标牌执行": true,
  "确认标牌执行": false,
  "校验绑定标牌文字": true,
  "标牌": [],
  "开关": [],
  "区域": [],
  "迁移记录": []
}
```

没有 `传送` 配置段。旧 JSON 中的 `传送` 段和 `"类型":"传送"` 动作在加载时忽略/移除，并在 `迁移记录` 里说明。

## 旧配置迁移

支持旧 CommandTool 的中英文键与旧 SignCommand 配置。原始来源文件只读，新版不改写、不移动、不删除旧文件。

```text
/工具 迁移预览 commandtool "旧CommandTool配置完整路径" "明确的归属世界"
/工具 迁移 commandtool "旧CommandTool配置完整路径" "明确的归属世界"
/工具 迁移预览 signcommand "旧SignCommand配置完整路径"
/工具 迁移 signcommand "旧SignCommand配置完整路径"
```

- 旧记录本身有世界时保留，不用参数强行替换。没有世界且未指定参数的记录保持禁用，不能猜到当前世界或同时绑定全部地图。
- 旧 `Enable/启用` 仅控制旧区域，不能误禁用旧开关。
- 旧开关“忽略权限”保留为动作提权；旧标牌可空的“以管理员身份执行”继承旧全局默认。
- 旧区域 `Permission/权限` 是当次执行额外授予的权限，不是进入区域的门槛；`Group/用户组` 保留为本组或父组限制。
- 旧 `(0,0)` 空动作占位跳过；缺失世界、空动作等在迁移记录里说明。旧进入/倒计时提示文字保留供对照，但按当前“全静默”要求不自动展示。
- **旧传送动作不会迁移到 CommandTool**；加载时移除并记录，边界传送请使用 BoundaryTransfer。
- 同源同位置同内容再次导入不会多出一份绑定；同 ID 内容变了、双语字段冲突、危险管理自绑定等会拒绝整个导入，不静默丢数据。

## 安全边界

- 自动静默只约束本插件的执行调用链，不全局禁言、不按关键词吞聊天、不改动玩家手动执行原指令的提示。
- 使用 TShock 原生结果、普通 TSPlayer 消息和 ChatHelper 广播的指令受统一静默保护；第三方插件若故意切断 ExecutionContext、在独立定时器里发消息，或直接绕过标准聊天发送原始网络包，无法仅凭来源准确归属。
- 指令目录隐藏不等于能阻止任何第三方抓包/聊天审计插件记录原始输入。本版不删除服务器诊断日志。
- 普通非绑定实体仍由原版/TShock/其他保护插件处理。本插件不是全服防炸、全服防包作弊或任意插件代码沙盒。
- CommandTool 不执行传送；任何跨世界、坐标传送、边界落点安全判定都不在本插件范围内。

## 构建与验证

```powershell
dotnet build CommandTool.UnifierTSL.csproj -c Release -p:UtBase="官方UTSL发行版目录" -p:NuGetAudit=false
dotnet run --project tests/CommandTool.Tests.csproj -c Release -p:UtBase="官方UTSL发行版目录"
```

源码工程只编译 `native/*.cs`，旧 `source/` 与 `LegacyCompat.cs` 不参与发行版。使用发行版已有 DLL，不下载替换核心依赖。

离线探针不能代替真实客户端联机验收；正式上线前请用测试服完成：标牌点击/确认、普通与指令开关拆改、压力板触发、区域离开取消、重叠优先级、断线重连和配置热重载。
